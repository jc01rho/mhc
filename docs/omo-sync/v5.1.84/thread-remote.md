## Scope

The account-wide `RemoteSessionsPort` is now real over agentd: the tailnet daemon a device's `relayd.json` peer names
with an `agentd` object (address, port, tokenFile) answers the contract's ops over one TCP link of LF-delimited JSON
frames (`thread/remote/agentd/`). A device with no `agentd` entry keeps the mhc-relayd path unchanged, so the relay
daemon is not removed. That port carries the #14748 solo-probe gate's exclusion, rows 6/7 copying, reopening a parked
session, the fork leg's capability read, the attach event stream and its per-connection release. Two rows stay
`blocked` on parts of the live port that no contract op reaches yet: the fence and admission rules with the remote
session watch, and `remote_ops.rs`'s own attach-stream follow (the stream exists in the client; the consumer that reads
it is not written). The #14358 refusal mapping and its one re-attach stay ported where mhc already sends commands: the
attach pool and the gateway's `DeviceServicePort`.

## What landed

- New crate `crates/omo/omo-sdk-contract` (`maho-omo-sdk-contract`, lib `omo_sdk_contract`): the security-sensitive half of the
  omo SDK contract (slice P1a-s, #14949) and the code registry of slice P1a (#14948), file for file:
  `principal.ts` -> `src/principal.rs`, `principal-matrix/*.ts` -> `src/principal_matrix/*.rs` (57 lines, 351 refusals),
  `behaviour-changes.ts` -> `src/behaviour_changes.rs`, `codes.ts` -> `src/codes.rs`, `code-sources.ts` ->
  `src/code_sources.rs` (the SDK's own list), `namespaces.ts` -> `src/namespaces.rs`, `inputs/custody.ts` ->
  `src/inputs/custody.rs` (`AccountAdopt` takes a readable handle, never text), `results/custody.ts` ->
  `src/results/custody.rs` (`Adopted` and every closed custody answer), `results/auth-check.ts` ->
  `src/results/auth_check.rs`, `validate.ts` -> `is_principal` / `custody_input_accepts` / `session_answer_accepts`.
- Tests `tests/contract_suite.rs` port the contract-data cases of `script/sdk-parity/authority-contract.test.ts` and
  `contract.test.ts` (principals, refusal codes per namespace, B1-B7 evidence flag, closed custody answers field by field,
  the session canary, secret-as-text inputs).
- `assets/omo-latest/skills/omo-relay/scripts/sdk/ports.ts` synced (`opening` thread state) with its manifest entry.
- The root's typed call table as data (`bb8b61313a`, `5d2e861f2f`): `crates/omo/omo-sdk-contract` `src/calls.rs` carries
  `ROOT_CALLS` (134 rows over the 14 namespaces), each row's input schema as a `src/shape.rs` `Shape`, its answer shape
  (`value`/`thread`/`stream`) and its `waits` flag; `input_accepts` is `validate.ts`'s `inputAccepts` over every row, and
  `takes_deadline_option` is design 4.4's wait-options rule. `src/results/root.rs` carries the answer records the
  contract directory declares itself. Tests `tests/root_calls.rs` port the table cases of `contract.test.ts` and
  `contract-controls.test.ts`; the table agrees with the pinned TypeBox schemas on 4,398 generated probes, except the 19
  that name a JS handle (`api_key`, `signal`), which this crate rules have no JSON form.

## Not carried (gap)

- nothing in this track's paths: the remaining upstream code is TS parity tooling or a runtime JS host surface
  (`root-options.ts`, `cancellation.ts`'s signal plumbing, `failure.ts`'s stream classes, `ports.ts`, `gated.ts`,
  `descriptor-ahead.ts`) and the root object itself, which is slice P1b's. `results/threads.ts` re-exports the thread
  contract's records, which `maho-omo-gateway` carries.
- `SOURCE_CODES` unions the thread taxonomy and the remote codes with the SDK's list; only the SDK's list
  (`OMO_SDK_CODES`) is carried here, the other two live in the thread and remote crates.

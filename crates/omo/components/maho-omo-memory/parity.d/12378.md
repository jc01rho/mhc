mhc had no bwrap smoke probe at all: it selected the sandbox from an existence check, so an AppArmor-restricted host killed every reflection child at spawn. Only a definitive verdict is memoized; a timed-out probe is returned but re-run on the next spawn, and the identity sandbox reports the degraded state once and once more when it is restored.

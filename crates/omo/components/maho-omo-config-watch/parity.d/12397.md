Ancestor creation targets stop at the first directory holding `.git` (a directory or a worktree or
submodule file) and never include the user config parent (HOME), a directory containing it, or the
filesystem root. Existing `.omo` directories above the bound stay watched as config targets.
The six new upstream cases map to `creation_watches_stop_at_a_project_root_holding_git_while_higher_omo_stays_watched`,
`creation_watches_stop_at_a_git_file`, `creation_watches_stop_at_the_nearest_repo_root`,
`cwd_at_home_adds_no_ancestor_creation_target`,
`cwd_outside_home_and_any_repo_never_watches_the_filesystem_root` and
`cwd_outside_home_never_watches_a_directory_containing_home`. The reworded first upstream case maps
to `creation_watches_stop_below_the_user_config_parent`, and the existing
`default_agent_protected_paths_are_never_covered` and
`every_ancestor_creation_target_is_root_anchored` drop HOME from their expected creation set.

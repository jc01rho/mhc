- Adapted case: upstream "a throwing dialog reports one diagnostic" has no Rust counterpart because `confirm` returns `bool`; the diagnostic path is covered by `a_blocked_state_directory_reports_one_diagnostic` (the answer cannot be written).
- Divergence (docs/divergences.md SD-6): the question is put only when the omo config already enables telemetry, because mhc telemetry is opt-in.

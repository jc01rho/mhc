# 5184th - the thread host wire and the `pi.session` adapter (omo v5.1.83..v5.1.84, native-thread-host)

`src/thread_host.rs` is the engine side of the gateway's native thread component. `HostTransport` carries
`thread/live-surface.ts` `requestFrame` (senpi-task `withRpcSocket` + `authenticateRpcHost`) to an `rpc_host` endpoint over
maho-rpc's authenticated socket, and `SessionControl` adapts core `GenerationSessionControlActions` to
`thread/gateway/registration.ts` `SessionControlActionsPort`. Both TS paths are rows of the gateway crate
(`crates/omo/components/maho-omo-gateway/parity.d/5184th.md`); this crate adds no row of its own.
Verdicts: `docs/omo-sync/v5.1.84/native-thread-host.md`.

## Notes

- `omo.modelRouting.resolve` answers `{schemaVersion: 1, rows}` or a typed refusal
  (`cwd_unavailable`, `config_invalid`, `registry_unavailable`). Rows resolve without a distributor,
  so a read never advances a round-robin rotation. The parent service tier is `None`, matching what
  mhc's composed planner passes today.
- The live provider is generic over a load closure: maho-cli maps `load_senpi_omo_config` into
  `LiveConfigLoad`, so this crate gains no dependency. On-disk fixtures from the upstream test file
  are covered with in-memory loads here.
- `compose_task_engine_with_live_config` hands the provider to the planner only; the
  category-unavailable warning planner still reads the composition-time snapshot (upstream reads the
  live config there too, `adc55342d6`); follow-up.
- Rows row-count test ports are partial: upstream iterates every builtin category with a fixture
  registry built from the chains; the Rust port does the same for the builtin pick and for agents,
  and checks the user-override promotion on two categories.

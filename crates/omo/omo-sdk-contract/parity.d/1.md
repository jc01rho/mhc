Notes:

- `code-sources.ts` carries only the SDK's own list (`OMO_SDK_CODES`); `SOURCE_CODES` also unions the thread taxonomy and
  the remote codes, which live in the thread and remote crates.
- `validate.ts` `inputAccepts` is carried for every row (`src/calls.rs` `input_accepts`, `5184s`); the credential-bearing
  calls defer to `custody_input_accepts`, and a call whose input is a readable handle or a callback (`account.adopt`,
  `account.signIn`, `sync.*`) accepts no JSON value.
- TypeBox `Type.String({ minLength: 1 })` is `schema::Text`, `Type.Literal(true)` is `schema::True`, a closed object is
  `#[serde(deny_unknown_fields)]`; a union with a `kind` tag is an internally tagged enum of closed structs.
- The authority-contract cases that read the TS registry rows, the scenario files, the security design document or the
  engine snapshot (matrixProblems against the document, scenario coverage, the engine pin guard) stay with the TS
  parity tooling; the contract-data half of each is asserted here. contract.test.ts's root-type and scenario cases
  type the SDK root this crate does not carry.

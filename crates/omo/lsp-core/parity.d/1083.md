Upstream sets `process.env.PATH`; the Rust tests pass the same value through `ResolveServerBinaryOptions::path_env` so no test mutates the process environment. Upstream drives interleavings by microtask turns; the Rust tests poll each waiter once (`now_or_never`) so it is counted before the gate opens, then sweep the same number of scheduler yields on a current-thread runtime. Tests that need symlinks or executable bits are Unix-only. Upstream `withHostJsRuntime` is not ported because mhc spawns the resolved binary directly.

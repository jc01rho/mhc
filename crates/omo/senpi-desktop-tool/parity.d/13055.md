`resolve_computer_settings` accepts and validates the five keys the omo config schema now passes
through (`computer.showCursor`, `run_sandbox`, `intervention`, `macos_key_priming`, `trace`), so a
config that sets them no longer fails resolution with an unknown-property error. They are not
carried into `ComputerSettings` yet: the engine-side behaviour (intervention policy, key priming,
traces, the cursor overlay switch) is the desktop track's port. Tests:
`tests/host_settings.rs` (`resolve_computer_settings_accepts_the_reserved_v2_keys_and_the_cursor_switch`,
`resolve_computer_settings_rejects_reserved_keys_outside_their_values`).

Tests: `tests/vectors.rs` (HMAC vectors, canonical base64url, oversized-line resync, chunk
arithmetic, blob reassembly and digest mismatch), `tests/handshake.rs` (a stale token is refused
before any request, an insecure state dir before connecting, a welcome without the right proof),
`tests/unit_mode_0644.rs` (units written 0644 under umask 077, an unchanged 0600 unit repaired
with no reload or restart, install and uninstall command sequences, quoting, readback).

Not ported: the delivery consumer and registrant (they serve the hosted relay's wake path), the
Windows DACL check (the client takes the documented loopback TCP endpoint and refuses nothing
else there).

`create_http_client` picks `McpTransportSpec::Sse` for an explicit `type: "sse"` and Streamable HTTP
otherwise, the same split as upstream's `transportKind`. The transport itself is the SDK's
`SSEClientTransport`, ported into `maho-ext-mcp` (`src/transport_sse.rs` and the `Sse` arm of
`src/transport_sdk.rs`): the GET event stream opens with the first send, after OAuth is installed,
and the POST endpoint it announces must share the stream's origin.

`withConnectDeadline` has no separate Rust form. The native connect is `initialize` under the 30 s
request budget (`connect_with_policy_signal`), and the wait for the `endpoint` event happens inside
that request, so a server that never announces its endpoint fails the connect with a request
timeout and the client closes the GET stream, as upstream does at its 60 s SDK budget.

Divergence (safety): the SSE client follows same-origin redirects only, so a redirect cannot carry
the configured headers or the bearer to another host; upstream's EventSource follows any redirect.

# Todo12815 git timeout diagnostics

| TS source file (omo) | Rust source file (mhc) |
|---|---|
| packages/memory-core/src/git/timeout-diagnostics.ts | crates/omo/memory-core/src/git/timeout_diagnostics.rs |

Opt-in evidence for a git that outlives its timeout: when OMO_GIT_TIMEOUT_DIAGNOSTICS_DIR names a directory, the timeout writes the live process table (ps, or Win32_Process with thread wait states on Windows) to git-timeout-<pid>-<ms>.json before git is signalled. The table is captured through an owner-only temp file, never a pipe, so a host with thousands of processes cannot overflow it.

What landed:

- `/v1/sync/entries` batch rows may carry the contract's 22-character base64url `batch_id`; a null,
  malformed, or keyring-row id is still refused (#12277, #12292).
- A received key that names a symlinked path, an escape from the repository root, a non-regular leaf
  (a FIFO would block the read forever), or a path git for Windows cannot stage is refused for this
  device before its render record exists; capture never follows a symlink (#12147, #12158, #12568).
- Every sync and account request carries `omo-contract-version: 1.44.0` and
  `omo-sync-capabilities: phrase`; a route without them misses the service floor (#13691).

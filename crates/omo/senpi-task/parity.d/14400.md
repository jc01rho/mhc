## Notes

- The ten builtin categories, their defaults, descriptions, caller guidance, prompt appends, gate
  model lists and fallback chains equal v5.1.79, including `deep-low` / `deep-high` and the Claude
  Fable 5.2 / 5.1 rungs of `architect`, `artistry`, `visual-engineering` and `plan-consultant`.
  The retired `deep` name resolves as `deep-low` through `omo_config_core::canonical_category_name`
  unless a user category of that name exists.
- Gates and rung resolvability are provider scoped (#9146): a rung resolves only on a provider it
  lists, directly or through `transform_model_for_provider`; a dead chain names the
  `unlisted_provider_model` a user may pin. `ResolveCategoryOptions.system_default_model` is gone, as
  upstream: a category never resolves outside its own chain.
- SD-20 is kept: the `architect` category stays advisory by default; the implementing wording ships
  only for `categories.architect.allow_edits: true`.
- GATE-1 (docs/divergences.md): every registry view the category and agent resolvers walk
  (`model_exclusion::without_config_excluded_models`) also hides Claude Fable models while
  `model_policy.block_fable` is on, so a Fable rung is skipped like a model with no login.
  `gate_tests.rs` (6) covers the gate; the upstream ports above run with the gate off.

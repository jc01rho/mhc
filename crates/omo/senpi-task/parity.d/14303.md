- `terminate.ts` (#14106, #14300/#14303): the Windows tree kill races the tool's end against the
  child's exit inside one 2 s window and observes the exit for a bounded window. The SIGKILL
  fallback after a silent `taskkill` is not ported: the reaper thread owns the OS child, so this
  module holds no handle to kill.
- `heartbeat.ts` (#10993 via #11706): probes carry `senpi-task_heartbeat_N` ids. The
  `RPC_REQUEST_DEADLINE_MS` export has no counterpart; this protocol client sets no per-request
  deadline. The cold-revive residency watchdog itself is a TS test fixture.
- `host-session-end.ts` (#11765, #11783): the TS `pending` close collapses, as in
  `host_session_close.rs`: the close is synchronous, so a pass settles before it returns. The
  third ownership case (the destruction port during run N's close) has no Rust test; the shared
  flight table covers it through the same `end_host_session_child` entry point.
- `anthropic-categories.ts` (#12239): shipped behind `categories.architect.allow_edits`
  (divergence SD-20); the default keeps the advisory-only architect.

## Notes

- `ResolveCategoryOptions` / `ResolveAgentOptions` carry `distribute_models:
  Option<Arc<ModelDistributor>>`; only the spawn planner sets it, so `omo.modelRouting.resolve` and
  every other read leave rotations alone.
- A round-robin canonical chain drops the builtin chain rungs from the runtime retry chain, and a
  round-robin agent ignores its single `model` when `models` is set, as upstream.
- `CategoryModelSelection.source` / `ResolvedAgent.model_source` answer who chose the model; a builtin
  agent whose model/models still equal its builtin definition is `Builtin`, anything else `User`.

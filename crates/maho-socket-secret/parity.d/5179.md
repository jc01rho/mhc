# Todo 5179: maho-socket-secret (senpi socket-transport secret lifecycle, snp-rpc track)

New crate; it has no audited senpi source root. Upstream is `packages/coding-agent/src/modes/rpc/socket-transport.ts`
at senpi v2026.11.19-5 (omo-desktop-app#4199 design 4.2-4.5), not the Windows adapter `crates/senpi-socket-secret`.
Tests: 14 in `tests/socket_secret.rs` (9 of them unix-only: modes, no-replace publication, contention, symlink and
invalid-entry refusals) and 3 unit tests in `src/lib.rs`.

| upstream symbol | Rust |
|---|---|
| `readSecretEntry` (regular files only, `O_NOFOLLOW`, read up to one byte past the valid length) | `read_secret_entry`, `read_valid_socket_secret` |
| `createSocketSecret` (never replaces; refuses an invalid entry) | `create_socket_secret` |
| `publishSocketSecretIfAbsent`, `writeStaging`, `syncDirectory`, `stagingPath` | `publish_secret_if_absent`, `write_staging`, `sync_directory`, `staging_path` |
| `replaceSocketSecret` | `replace_secret` |
| the locked half of `ensureSocketSecret` | `provision_socket_secret_locked` (the async wrapper that takes the lock is `maho-rpc` `socket_transport::ensure_socket_secret`) |
| `socketSecretLockPath` | `socket_secret_lock_path` |
| `writeSocketSecretInPlace` (win32 only) | `write_secret_in_place` (non-unix) |

Not ported: the Windows adapter crate `senpi-socket-secret` (owner-only DACL, `CREATE_NEW` staging, presence guards,
volume locality, process identity) and `socket-secret-native.ts` / `socket-secret-publish.ts`; no senpi code calls them
yet, and senpi keeps the in-place writer on win32.

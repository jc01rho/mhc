# senpi-desktop-xpc parity (omo v5.1.79 import)

Imported from omo `crates/senpi-desktop-xpc` at oh-my-openagent v5.1.79 (822bd92303) (the crate existed upstream since before
v5.1.52 and was never imported). Package `maho-senpi-desktop-xpc`, lib `senpi_desktop_xpc`. Every
module, test, example, script and `TRANSPORT.md` is the upstream file, rustfmt-normalized.

The engine uses it for its `--xpc` agent mode on macOS, where the OmO desktop app hosts the engine
over XPC and the persistent stop latch lives under the app's ComputerControl state directory; the
stdio and `--serve` modes mhc uses do not touch it. Off macOS only `roles` compiles.

Divergence: the crate sets `unsafe_code = "deny"` and each FFI module (and the FFI test, example
and crash-test modules) opens with `#![allow(unsafe_code)]`; every unsafe block keeps its upstream
SAFETY comment.
